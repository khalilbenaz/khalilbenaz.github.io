La suite de gestionnaires multi-sessions pour agents IA en terminal. Fini la jungle des onglets de terminal : bénéficiez d'états en temps réel, de Git worktrees isolés, de sessions persistantes et d'une file d'attente intelligente.

v3.3.3

Claude Sessions Manager

Spécifiquement conçu pour Claude Code (Anthropic)

Pilotez vos agents Claude Code en parallèle : suivi des tokens et coûts, détection des demandes d'approbation d'outils, historique et bibliothèque de prompts.

  • CLI cible : claude (Anthropic Claude Code)
  • Port par défaut : 7890 (commande csm)
  • Modèles : Claude 3.7 Sonnet, Claude 3 Opus, Haiku
  • Effort : low, medium, high, max
  • Worktrees Git : Branches isolées automatiques
  • Sécurité : Verrouillage individuel par mot de passe
$ npm i -g claude-sessions-manager && csm install

AGY Sessions Manager

Spécifiquement conçu pour Antigravity CLI (Google DeepMind)

Pilotez vos agents Antigravity CLI (agy) : installation et mises à jour automatiques du CLI, sélection harmonisée des modèles et niveaux d'effort adaptatifs.

  • CLI cible : agy (Google Antigravity CLI)
  • Port par défaut : 7892 (commande asm)
  • Modèles : Gemini 3.8/3.7 Flash, Gemini 3.1 Pro, Claude Sonnet 4.6, GPT-OSS
  • Auto-install : Installe et met à jour agy automatiquement
  • Effort adaptatif : Sélection anti-conflit selon le modèle choisi
  • Worktrees Git : Branches isolées et reprise transparente
$ npm i -g agy-sessions-manager && asm install

💡 Pourquoi et comment utiliser les deux en même temps ?

Claude Sessions Manager et AGY Sessions Manager ont été conçus pour cohabiter parfaitement sans aucun conflit : ports distincts (7890 vs 7892), variables d'environnement étanches, services d'arrière-plan indépendants (csm et asm).

Vous pouvez ainsi lancer simultanément vos sessions d'analyse avec Gemini Flash ou Pro dans AGY Sessions, tout en confiant vos implémentations complexes à Claude 3.7 Sonnet dans Claude Sessions !
